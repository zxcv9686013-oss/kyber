// 02 — Kyber Language

One environment.
Multiple compute domains.

Kyber brings high-level programming and low-level heterogeneous workflows into one compiler environment.

Unified compilation Build projects through a single Kyber toolchain.
Embedded workflows Integrate C, C++, CUDA, XASM and specialized compute pipelines.
Native compiler pipeline Lower programs through AST and LLVM-based intermediate representation.
