# Inline CUDA — zero glue code
#extern "cuda" {
    __global__ void addKernel(float* c, float* a) {
        int i = threadIdx.x;
        c[i] = a[i] * 2.0f;
    }
}
Why Kyber

One language.
Every backend.

Stop gluing together five different tools. Kyber handles CUDA, AI layers, assembly, webhooks, and C++ in a single file.

⚡

LLVM-Powered

Compiles directly to native machine code via LLVM. No interpreter, no VM — just fast binaries.

🖥️

CUDA & NGPU

Embed GPU kernels inline with #extern "cuda" or write NGPU code that compiles to PTX automatically.

🧠

AI Native

First-class tensor, matrix, and layer types. Dense, ReLU, Conv built in.

🔗

C/C++ Interop

Drop raw C or C++ blocks directly into Kyber with #extern "c++". No bindings needed.

🔧

XASM

Write assembly inline with #extern "xasm". Kyber compiles it alongside your high-level code.

🌐

N8N Webhooks

Trigger n8n workflows directly from Kyber code with #n8n blocks. No HTTP boilerplate.

Get Started

Install Kyber

Requires Python 3.8+ and Windows 10/11. The installer sets up everything and adds kyberc to your PATH.

python install.py
kyberc yourfile.kyber

Or download the installer directly: install.py
