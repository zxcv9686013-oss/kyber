// 02 — Language

Write once.
Target the machine.

Kyber is designed to combine high-level programming with low-level heterogeneous compute workflows.

Unified compiler One project can contain multiple compute domains.
Embedded backends Integrate C, C++, CUDA, XASM and other workflows.
LLVM-based pipeline Lower source programs toward optimized intermediate representations.
